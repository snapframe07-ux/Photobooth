# SnapFrame

เว็บถ่าย Photo Strip เลือกกรอบ ตกแต่งภาพ และบันทึกเทมเพลต

## เริ่มใช้งาน

- `npm install` ติดตั้งแพ็กเกจ
- `npm run dev` เปิดเว็บสำหรับพัฒนา
- `npm test` ตรวจการจัดช่องภาพ ฟิลเตอร์ เทมเพลต และฟังก์ชันที่ใช้ร่วมกัน
- `npm run build` สร้างเว็บใน `dist/`

ตั้งค่า Supabase ตาม `.env.example` ใน `.env.local` เมื่อต้องการใช้บัญชีและคลังออนไลน์

## โครงสร้าง

- `src/main.js` เชื่อมสถานะแอป เหตุการณ์จากผู้ใช้ และโมดูลต่าง ๆ
- `src/data/catalogs.js` รายการกรอบ สติกเกอร์ และฟิลเตอร์ที่ติดมากับแอป
- `src/ui/appLayout.js` HTML ของหน้าหลักและหน้าต่างโต้ตอบ
- `src/ui/assetGallery.js` ขั้นตอนโหลดและลบรายการที่กรอบกับสติกเกอร์ใช้ร่วมกัน
- `src/ui/appUI.js` สถานะแท็บและภาพที่เก็บในเซสชัน
- `src/modules/` กล้อง แคนวาส โหลดภาพ ฟิลเตอร์ ตัดพื้นหลัง จัดช่องภาพ และ Supabase
- `src/styles/` สไตล์แยกตามหน้าที่ โดย `src/style.css` กำหนดลำดับนำเข้า
- `src/assets/` ภาพ กรอบ และสติกเกอร์
- `public/` ไฟล์ที่ให้บริการโดยตรง
- `*.sql` สคริปต์ตั้งค่าฐานข้อมูล Supabase

วางไฟล์ `*.test.js` ข้างโมดูลที่ทดสอบ ใช้ตัวทดสอบที่มีใน Node.js โดยไม่เพิ่มแพ็กเกจ
รักษาลำดับนำเข้า CSS เพื่อให้กฎ responsive และกฎที่เขียนทับก่อนหน้าทำงานเหมือนเดิม

## กล้อง การแชร์ภาพ และเทมเพลต

- ปุ่ม “สลับกล้อง” อยู่ใต้ภาพพรีวิว เลือกกล้องหน้า/หลัง และกลับมาเปิดกล้องเดิมถ้าเปลี่ยนไม่ได้
- หลังถ่าย กด “แชร์ภาพไปโซเชียล” ในหน้าตกแต่ง เพื่อเปิดเมนูแชร์ของอุปกรณ์ แอปปลายทางขึ้นอยู่กับอุปกรณ์และแอปที่ติดตั้ง ถ้าแชร์ไฟล์ไม่ได้ให้บันทึกภาพแล้วแนบในแอปเอง
- เปิดเว็บผ่าน HTTPS เมื่อใช้กล้องและแชร์บนมือถือ/แท็บเล็ต
- เทมเพลตที่บันทึกใหม่ฝังภาพสติกเกอร์และกรอบเป็น PNG ในข้อมูลเทมเพลต โดยไม่ฝังภาพถ่ายฐาน จึงไม่ผูกกับลิงก์ชั่วคราวหรือสิทธิ์เข้าคลังสติกเกอร์ของเจ้าของ ข้อมูลเทมเพลตจะใหญ่ขึ้นตามภาพตกแต่งที่ใช้
- เทมเพลตเก่าที่มีลิงก์ `blob:` หมดอายุต้องอัปโหลดสติกเกอร์ต้นฉบับและบันทึกใหม่

ก่อนนำไปใช้จริง ให้ลองกล้องหน้า→หลัง→หน้า ถ่ายพร้อมสติกเกอร์ แชร์ภาพไปแอปที่ติดตั้ง และเปิดเทมเพลตที่แชร์ด้วยอีกบัญชีบนอีกอุปกรณ์
